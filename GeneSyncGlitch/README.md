# THE GENESYNC GLITCH

Canonical story source for the ShareCapsule `/novels/` reader.

## Reader contract

- `book.json` provides book-level metadata and cover artwork.
- Chapter Markdown remains the canonical manuscript.
- Each reader chapter lives in its own Markdown file.
- Chapter front matter provides cinematic reader metadata such as `title`, `chapter_title`, `subtitle`, `mood`, and `scene`.
- Ambient audio is optional and intentionally omitted for now.
